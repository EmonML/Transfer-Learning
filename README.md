***Brain Tumor MRI Classification using Transfer Learning***

A Deep Learning project for classifying brain MRI images into four different categories using Transfer Learning with Xception and TensorFlow/Keras.

The project includes dataset exploration, visualization, image preprocessing, model training, validation, testing, performance analysis, confusion matrix, classification prediction, and single-image inference

***Overview***

Brain tumor classification from MRI images is an important computer vision application in the medical imaging domain. This project uses a pretrained Xception CNN architecture with ImageNet weights and adapts it for four-class brain tumor classification.

The model receives an MRI image as input and predicts one of the following classes:

**1. Glioma**

**2. Meningioma**

**3. No Tumor**

**4. Pituitary**
